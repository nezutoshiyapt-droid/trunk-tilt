# 体幹傾斜・恐怖感測定アプリ

胸骨前面にハーネス固定したiPhoneで、**体幹傾斜角・角速度・直線加速度**を同時計測し、各条件でのNRS（転倒恐怖感）を記録するWebアプリです。単一のHTMLファイルで動作します。

---

## 1. 公開手順（GitHub Pages）

iPhoneのSafariは **HTTPS でないとモーションセンサーもカメラも使えません**。GitHub Pagesで無料公開するのが最短です。

1. GitHubで新しいリポジトリを作成（例: `trunk-tilt`）。Publicにする
2. `index.html` をアップロード（Add file → Upload files → Commit）
3. リポジトリの **Settings → Pages** を開く
4. Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save
5. 1〜2分後、`https://<ユーザー名>.github.io/trunk-tilt/` が発行される
6. そのURLをiPhoneのSafariで開く（ホーム画面に追加しておくと便利）

> Privateリポジトリでは Pages が使えない場合があります。被検者情報はアプリ内に一切送信されない（すべて端末内処理）ため、コード自体はPublicで問題ありません。

---

## 2. iPhone側の事前設定

- **Safari** で開くこと（Chrome for iOSでは動作しません）
- 設定 → Safari → **「モーションと画面の向きのアクセス」を ON**
- 設定 → 画面表示と明るさ → 自動ロック → **なし**（アプリ側でもスリープ防止を試みます）
- 動画録画には **iOS 14.3 以降** が必要です（iPhone 6s/7 は iOS 15.8 まで更新可）。
  未対応の場合はアプリが自動で検知し、録画OFF・ビープ音のみで動作します
- 初回起動時に「モーションセンサー」「カメラ」「マイク」の許可ダイアログが出ます。**すべて許可**

## 3. 装着

| 項目 | 指定 |
|---|---|
| 位置 | 胸骨前面（剣状突起〜胸骨柄の中間あたり） |
| 画面の向き | **前（外向き）** |
| 本体上端 | **頭側** |
| 固定 | ハーネスで、体幹に対してズレ・ガタつきがないこと |

前面カメラは検者・室内側を向きます。患者本人は写りませんが、**いつ・どちら向きに傾けたか**が映像で確認でき、ビープ音が同じ音声トラックに入るため外部カメラとの同期も可能です。

## 3.5 プロトコル（転倒恐怖感シート準拠）

1セッション＝**4ブロック**。「測定方法」が `Ao` なら次の順に実施します。

| ブロック | 開眼/閉眼 | 平面 |
|---|---|---|
| 1 | 開眼 | 前額面 |
| 2 | 開眼 | 矢状面 |
| 3 | 閉眼 | 前額面 |
| 4 | 閉眼 | 矢状面 |

`Ac` の場合は閉眼2ブロックが先になります。

各ブロックは **正中位 ＋ 傾斜8工程** の計9工程。各パターンは4角度を2回ずつ、順序を釣り合わせた配列です。

**前額面**（P＝麻痺側、N＝非麻痺側）

| | ① | ② | ③ | ④ | ⑤ | ⑥ | ⑦ | ⑧ |
|---|---|---|---|---|---|---|---|---|
| A | P15 | N30 | N30 | P15 | N15 | P30 | P30 | N15 |
| B | N30 | P15 | P15 | N30 | P30 | N15 | N15 | P30 |
| C | P30 | N15 | N15 | P30 | N30 | P15 | P15 | N30 |
| D | N15 | P30 | P30 | N15 | P15 | N30 | N30 | P15 |

**矢状面**（F＝前方、B＝後方）

| | ① | ② | ③ | ④ | ⑤ | ⑥ | ⑦ | ⑧ |
|---|---|---|---|---|---|---|---|---|
| A | F15 | B30 | B30 | F15 | B15 | F30 | F30 | B15 |
| B | B30 | F15 | F15 | B30 | F30 | B15 | B15 | F30 |
| C | F30 | B15 | B15 | F30 | B30 | F15 | F15 | B30 |
| D | B15 | F30 | F30 | B15 | F15 | B30 | B30 | F15 |

NRSはアプリでは入力しません（別紙のシートに記入）。アプリは角度・角速度・加速度・時刻・動画のみを記録します。

## 4. 使い方

### ① 設定画面
被検者ID・検者名・**麻痺側（左/右）**・**パターン（A〜D）**・**スタート条件（開眼/閉眼）**を選択。選ぶと4ブロックの構成と各平面の傾斜順が画面に表示され、確認できます。

### ② 装着・センサー確認（重要）
1. **STEP 1**：被検者に楽な座位でまっすぐ座ってもらい「直立座位で押す」→ 重力符号の自動判定と装着オフセットの確認。オフセットが8°を超える場合はハーネスを調整
2. **STEP 2**：実際にゆっくり前に傾け「前傾＋」、右に傾け「右＋」になるか確認。逆なら符号反転ボタン
   - 画面が外を向いているため、**左右は初期設定で反転済み**です。必ず実機で確認してください
3. **STEP 3**：「ジャイロ較正」を押し、5秒間ゆっくり前後・左右に傾ける
   - 較正するとジャイロ＋加速度の相補フィルタが有効になり、傾斜中の並進加速度による角度誤差が減ります
   - 較正できなくても加速度センサーのみで測定可能です

### ③ ブロック選択
4ブロックが順に並びます。上から実施してください（任意のブロックをタップして開始も可）。

### ④ 測定
1. **ブロック開始**を押す → 同期ビープ2回 → 録画開始 → 自動で①正中位へ
2. 画面上部に**現在の指示**が大きく出ます（例:「非麻痺側（左）へ **30°**」＋開眼/閉眼バッジ）。下の一覧で全9工程と現在位置が確認できます
3. 指示どおりに傾ける。速度ゲージが**緑**に収まるようにゆっくり動かす
   - 上限超過で赤表示＋警告音。加速度差による恐怖感の混入を抑えます
4. 鉛直に戻すと自動で工程完了 → 設定した秒数のインターバル後、次の指示に切り替わります
   - **画面に触れずに8工程を通せます**（胸装着のスマホを触るとアーチファクトが出るため）
5. うまく判定されないときは「**次の工程へ**」で手動送り、「**この工程をやり直す**」で再測定
6. 8工程が終わると自動でブロック終了 → 録画停止 → ブロック選択に戻ります

音声読み上げはありません。既定では**ブロック開始・終了のビープのみ**が鳴ります（動画・外部カメラとの同期用）。各傾斜の開始・到達ビープは被検者への手がかりになるため既定でOFFです。

### ⑤ 結果・出力
ブロック選択画面の「結果とデータ出力へ」→ 一覧表とダウンロードリンク。

## 5. 出力データ

### `<ID>_<方法>_<日時>_summary.csv` — 工程サマリー（1行 = 1工程、最大36行）

| 列 | 内容 |
|---|---|
| `method` | 測定方法（Ao / Bc など） |
| `block_no` / `eye` / `plane` | ブロック番号 / open・closed / frontal・sagittal |
| `step_no` / `step_code` / `direction` | 工程番号（0＝正中位）/ P15・N30・F15・B30 等 / 表示した方向名 |
| `target_deg` | 目標角（前＋/後−、右＋/左−の符号付き） |
| `peak_angle_deg` | 目標方向への到達最大角 |
| `hold_mean_angle_deg` | 保持相の平均角（正中位工程では静止時の平均角） |
| `tilt_duration_s` | 傾斜開始→目標到達の所要時間 |
| `mean_angvel_dps` | 平均角速度（到達角 ÷ 所要時間） |
| `peak_angvel_dps` | 最大角速度 |
| `peak_linacc_ms2` | 最大合成直線加速度（重力除去済） |
| `hold_duration_s` | 保持時間 |
| `t_step_start_ms` / `t_tilt_start_ms` / `t_reach_ms` / `t_end_ms` | **ブロック開始（＝動画0秒）からの時刻** |
| `video_file` | 対応する動画ファイル名 |

NRS列はありません。別紙シートの値は解析時に `block_no` + `step_no` で突き合わせてください。

### `<ID>_<方法>_<日時>_raw.csv` — 生波形（約60 Hz、全ブロック結合）

`t_ms`（ブロック開始基準）, `block`, `eye`, `plane`, `pattern`, `step_no`, `step_code`, `target_deg`,
矢状面角/前額面角, 加速度センサーのみの角度, 角速度, 生ジャイロ3軸, 直線加速度3軸＋合成, 重力ベクトル3軸, `phase`, `event`。

`event` 列に `MID_START` / `MID_END` / `STEP_START` / `TILT_START` / `TARGET_REACHED` / `RETURN_END` / `STEP_END` / `MANUAL_NEXT` / `REDO` / `LAP1` … が入ります。オフライン再解析はこの列を基準に区間を切ってください。

### 動画
1ブロックにつき1ファイル（`P001_B1_o_FRO_A.mp4` など）。動画の 0 秒 ＝ ブロック開始 ＝ CSVの `t_ms = 0` です。
iPhoneではリンクをタップ → 共有 → 「ビデオを保存」で写真アプリに保存できます。

> **注意**: データは端末のメモリ上にあります。結果画面でCSV・動画をすべてダウンロードしてからブラウザを閉じてください。

## 6. 角度の定義

重力（鉛直）を 0° とする絶対角です。装着オフセットは減算していません（表示・記録は絶対角のみ）。

- 矢状面角 = `atan2(g_z, √(g_x²+g_y²))` … 端末前方向への傾き（前傾 +）
- 前額面角 = `atan2(g_x, √(g_y²+g_z²))` … 端末右方向への傾き（初期設定で反転し、患者の右傾斜が +）

単一平面の傾斜では厳密に一致します（検証済: 前傾20°入力→20.00°出力）。矢状・前額が同時に大きく生じる複合傾斜では、この分解式の性質上わずかに相互干渉します（例: 前傾20°＋側屈30°同時 → 矢状17.2°表示）。本プロトコルは単一平面課題のため実用上の問題はありませんが、複合成分が疑われる試行では `raw.csv` の重力ベクトル3軸から任意の定義で再計算できます。

---

## 7. 測定上の注意

- **同一被検者内で傾斜速度をそろえる**ことが本アプリの主目的です。速度ゲージが緑に収まる範囲（初期値 3–8 deg/s）で操作し、`peak_angvel_dps` と `peak_linacc_ms2` を共変量として保持してください
- 端末に触れると加速度アーチファクトが出ます。自動検出をONにして、傾斜中は画面に触れない運用を推奨します
- 傾斜は徒手介助で行うため、検者の手の力の入り方も速度に影響します。試行間の速度のばらつきは `summary.csv` で必ず確認してください
- 転倒リスクのある被検者では、必ず前後左右に介助者を配置してください
- 本アプリは研究用途を想定した記録支援ツールであり、医療機器ではありません

## 8. うまく動かないとき

| 症状 | 対処 |
|---|---|
| 角度が0のまま／`0 Hz` | HTTPSで開いているか確認。Safari設定の「モーションと画面の向きのアクセス」をON。ページを再読み込みして「許可」 |
| 前後・左右の符号が逆 | 装着確認画面の「符号反転」ボタン |
| 角度がじわじわドリフトする | ジャイロ較正をやり直す。それでも続く場合は較正せず加速度のみモードで使用（ドリフトしません） |
| 傾けていないのに角度が振れる | 較正未実施だと並進加速度の影響を受けます。STEP 3 のジャイロ較正を実施 |
| 録画ボタンが灰色 | iOSが14.3未満。設定→一般→ソフトウェア・アップデートで更新するか、外部カメラ＋ビープ同期で運用 |
| 動画が保存できない | 結果画面のリンクを長押し → 「リンク先のファイルをダウンロード」またはタップ後に共有シートから保存 |
| 途中でSafariが落ちる | 録画の解像度が重い可能性。他アプリを終了し、試行数を分けて実施 |
