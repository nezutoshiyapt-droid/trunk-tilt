# 体幹傾斜・恐怖感測定アプリ

胸骨前面にハーネス固定したiPhoneで、**体幹傾斜角・角速度・直線加速度**を同時計測し、転倒恐怖感シートの手順どおりに傾斜課題を進行・記録するWebアプリです。オフライン対応（PWA）で、初回にオンラインで開けば以降は機内モードでも動作します。

---

## 1. 公開手順（GitHub Pages）

iPhoneのSafariは **HTTPS でないとモーションセンサーもマイクも使えません**。GitHub Pagesで無料公開するのが最短です。

1. GitHubで新しいリポジトリを作成（例: `trunk-tilt`）。Publicにする
2. `index.html` `sw.js` `manifest.webmanifest` `icon-180.png` `icon-512.png` をアップロード（Add file → Upload files → Commit）
3. リポジトリの **Settings → Pages** を開く
4. Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save
5. 1〜2分後、`https://<ユーザー名>.github.io/trunk-tilt/` が発行される
6. そのURLをiPhoneのSafariで開く（ホーム画面に追加しておくと便利）

> Privateリポジトリでは Pages が使えない場合があります。被検者情報はアプリ内に一切送信されない（すべて端末内処理）ため、コード自体はPublicで問題ありません。

> アップロードするファイルは5つです：`index.html` / `sw.js` / `manifest.webmanifest` / `icon-180.png` / `icon-512.png`

## 1.5 オフラインで使う（病棟・訪問先など）

**測定時にネットワークは不要です。** 一度だけオンラインでアプリを開けば、端末内にアプリ本体が保存され、以降は機内モード・圏外でも動作します。

### なぜ「HTMLファイルを直接開く」ではダメか

iOS Safariは、モーションセンサー（`DeviceMotionEvent.requestPermission`）とマイク（`getUserMedia`）を**HTTPSで配信されたページにしか許可しません**。HTMLファイルをiPhoneにコピーして `file://` で開くと、角度もマイクも取得できません。そのため「HTTPSで一度読み込み → 端末内に保存 → オフラインで実行」という形にしています。

### 手順（初回のみ、Wi-Fi環境で）

1. iPhoneのSafariでアプリURLを開く（「Safariでのオフライン準備 完了」と出ます）
2. 画面下の**共有ボタン** → 「**ホーム画面に追加**」→ 追加
3. **追加したアイコンから、オンラインのまま一度起動する**。画面上部に「**オフライン準備 完了**　このホーム画面アプリは機内モード・圏外でも測定できます」と青い帯が出るのを確認（数秒かかります）
4. 以降はホーム画面のアイコンから起動。**機内モードでも動きます**

> 手順3が必要な理由：iOSでは、Safariとホーム画面アプリでデータの保存先が別になることがあります。Safariで準備が済んでも、ホーム画面アプリには引き継がれない場合があるため、アイコンから一度オンラインで開いて保存させます。

ホーム画面から起動するとSafariのアドレスバーが消え、画面が広く使えます。

### 確認方法

機内モードにしてからホーム画面のアイコンで起動し、設定画面が正常に開けばOKです。「オフラインで動作中」と表示されます。

### 電波が弱い場所では

オンライン時は毎回最新版を取りに行きますが、**4秒待っても応答がなければ保存済みの版で起動**します（裏で通信は続け、届いたら次回から最新版に入れ替わります）。圏外ぎりぎりの病室などでも、起動を待たされることはありません。

### 注意

- 保存されるのはアプリ本体だけです。**測定データは常に端末内**で、オンライン・オフラインを問わず外部に送信されません
- アプリを更新した場合は、**一度オンラインで開き直す**と自動で最新版に入れ替わります（画面上部の青い帯に出る「版: trunk-tilt-v8」などの表示で確認できます）
- 長期間まったく起動しないとiOSがキャッシュを削除することがあります。測定日の前に一度、オンラインで起動しておくと確実です
- どうしてもインターネットに一度もつなげない場合は、研究室のPCでローカルHTTPSサーバーを立てて同一Wi-Fi内で配信する方法になりますが、証明書の設定が必要で手間がかかります

## 2. iPhone側の事前設定

- **Safari** で開くこと（Chrome for iOSでは動作しません）
- 設定 → Safari → **「モーションと画面の向きのアクセス」を ON**
- 設定 → 画面表示と明るさ → 自動ロック → **なし**（アプリ側でもスリープ防止を試みます）
- 録音・録画には **iOS 14.3 以降** が必要です（iPhone 6s/7 は iOS 15.8 まで更新可）。
  未対応の場合はアプリが自動で検知し、「記録なし」に固定されます（センサー記録は可能）
- 初回起動時に「モーションセンサー」「マイク」（動画モードでは「カメラ」も）の許可ダイアログが出ます。**すべて許可**

## 3. 装着

| 項目 | 指定 |
|---|---|
| 位置 | 胸骨前面（剣状突起〜胸骨柄の中間あたり） |
| 画面の向き | **前（外向き）** |
| 本体上端 | **頭側** |
| 固定 | ハーネスで、体幹に対してズレ・ガタつきがないこと |

既定は**音声のみの録音**です。傾斜の角度・タイミング・速度はセンサーCSVに全て残るため映像は必須ではなく、音声には検者の指示・被検者の発言・同期ビープが入ります。動画モードを選んだ場合、前面カメラは検者・室内側を向きます（被検者本人は写りません）。

## 3.5 プロトコル（転倒恐怖感シート準拠）

1セッション＝**2ブロック**。「測定方法」が `Ao` なら 開眼ブロック → 閉眼ブロック の順（`Ac` なら逆）。

**1ブロックの中身（全19工程）**

| 工程 | 内容 |
|---|---|
| 基 | 前額面 正中位（既定10秒） |
| ①〜⑧ | 前額面 傾斜8回 |
| － | 休憩・矢状面へ切り替え（既定20秒） |
| 基 | 矢状面 正中位（既定10秒） |
| ①〜⑧ | 矢状面 傾斜8回 |

**スマホ操作はブロック開始時の1タップのみ**です。以降は鉛直復帰の自動検出で工程が進みます。

各パターンは4角度を2回ずつ、順序を釣り合わせた配列です。

**前額面**（P＝麻痺側、N＝非麻痺側）

| | ① | ② | ③ | ④ | ⑤ | ⑥ | ⑦ | ⑧ |
|---|---|---|---|---|---|---|---|---|
| A | P15 | N30 | N30 | P15 | N15 | P30 | P30 | N15 |
| B | N30 | P15 | P15 | N30 | P30 | N15 | N15 | P30 |
| C | P30 | N15 | N15 | P30 | N30 | P15 | P15 | N30 |
| D | N15 | P30 | P30 | N15 | P15 | N30 | N30 | P15 |

**矢状面**（F＝前方、B＝後方）

| | ① | ② | ③ | ④ | ⑤ | ⑥ | ⑦ | ⑧ |
|---|---|---|---|---|---|---|---|---|
| A | F15 | B30 | B30 | F15 | B15 | F30 | F30 | B15 |
| B | B30 | F15 | F15 | B30 | F30 | B15 | B15 | F30 |
| C | F30 | B15 | B15 | F30 | B30 | F15 | F15 | B30 |
| D | B15 | F30 | F30 | B15 | F15 | B30 | B30 | F15 |

NRSはアプリでは入力しません（別紙のシートに記入）。アプリは角度・角速度・加速度・時刻と、音声（または動画）のみを記録します。

## 4. 使い方

### ① 設定画面
被検者ID・検者名・**麻痺側（左/右）**・**パターン（A〜D）**・**スタート条件（開眼/閉眼）**を選択。選ぶと2ブロックの構成と各平面の傾斜順が画面に表示され、確認できます。

### ② 装着・センサー確認（重要）
0. **STEP 0**：「静止ノイズを測る」→ 加速度センサーのノイズ量を2秒測定。**0.15 m/s²未満なら正常**です。故障を疑ったときはここで確認できます
1. **STEP 1**：被検者に楽な座位でまっすぐ座ってもらい「直立座位で押す」→ 重力符号の自動判定と装着オフセットの確認。オフセットが8°を超える場合はハーネスを調整
2. **STEP 2**：実際にゆっくり前に傾け「前傾＋」、右に傾け「右＋」になるか確認。逆なら符号反転ボタン
   - 画面が外を向いているため、**左右は初期設定で反転済み**です。必ず実機で確認してください
3. **STEP 3**：「ジャイロ較正」を押し、5秒間ゆっくり前後・左右に傾ける
   - 較正するとジャイロ＋加速度の相補フィルタが有効になり、傾斜中の並進加速度による角度誤差が減ります
   - 較正できなくても加速度センサーのみで測定可能です

### ③ ブロック選択
「開眼ブロック」「閉眼ブロック」の2つが並びます。上から実施してください。

### ④ 測定（開始後は操作不要）
1. **ブロック開始**を1回押す → 同期ビープ2回 → 録音開始 → 自動で前額面の正中位へ
2. 画面構成（上から）
   - **前額面と矢状面の角度・角速度を常時同時表示**（実施中の平面が青枠でハイライト）
   - 状態表示（「傾斜中」「目標到達 — 保持」「静止して基準を記録中 — 残り 7.3 秒」など）
   - 目標角ゲージ、傾斜速度ゲージ
   - **測定の順番**：`右15° → 左30° → 左30° → 右15° → …` と全16回を並べ、**今どれをやるかを大きく反転表示**。済んだものは薄くなります
   - 最大角・最大速度・最大加速度
3. 指示どおりに傾ける。速度ゲージが**緑**に収まるようにゆっくり動かす
   - 上限超過で赤表示＋警告音。加速度差による恐怖感の混入を抑えます
4. 鉛直に戻すと自動で工程完了 → 既定3秒のインターバル → 次の指示へ
5. 8工程が終わると休憩（既定20秒・カウントダウン表示）→ 矢状面へ自動で移行
6. 矢状面8工程が終わると自動でブロック終了 → 録音停止 → ブロック選択に戻ります

**補正が必要なときだけ**：順番の下にある小さな「◀ 1つ戻す」「1つ進める ▶」で修正できます。基準記録・休憩・工程間の待ち時間中は「**待ち時間をスキップして次へ**」ボタンが出ます（待ち時間以外のときは表示されません）。

麻痺側の左右は設定画面の選択から自動で変換され、順番表示は `右15°` のように**実際の左右**で出ます（前額面の見出しに「右＝麻痺側」と注記）。

音声読み上げはありません。既定では**ブロック開始・終了のビープのみ**が鳴ります（録音・外部カメラとの同期用）。各傾斜の開始・到達ビープは被検者への手がかりになるため既定でOFFです。

### ⑤ 結果・出力
ブロック選択画面の「結果とデータ出力へ」→ 一覧表と保存ボタン。「**すべて保存**」で工程サマリーCSV・生波形CSV・音声をまとめて保存できます。

### ⑥ 次の被検者へ
結果画面の「**次の被検者へ（最初の画面に戻る）**」で、アプリを閉じずに次の測定を始められます（被検者ID・麻痺側・パターン・スタート条件はリセットされるので、選び直してください）。前の被検者のデータは端末内に残ります。

## 4.5 データの保存と復元（v8〜）

### 保存のしかた
保存ボタンを押すとiPhoneの**共有メニュー**が開きます。「**"ファイル"に保存**」を選び、保存先のフォルダ（例：「このiPhone内」→ 研究用フォルダ）を指定してください。機内モードでも保存できます。

- ブロック終了時：ブロック選択画面の「このブロックのデータ」→「開眼（閉眼）ブロックのデータを保存」（生波形CSV＋音声）
- 全ブロック終了後：結果画面の「すべて保存」（工程サマリー＋生波形＋音声）
- 共有メニューを使うのは、ホーム画面アプリでダウンロード用リンクを開くと画面が止まり、アプリの強制終了が必要になることがあるためです（iOSの既知の不具合）

### 端末内の自動控え
各ブロックが終わると、そのブロックの生波形CSV・音声・工程結果が**端末内に自動で控えられます**（「✓ 端末内にも自動で控えを残しました」と表示）。外部には送信されません。

アプリが途中で閉じた・強制終了した場合も、次に起動すると最初の画面に「**端末内に残っている測定データ**」が表示されます。

| ボタン | 動作 |
|---|---|
| 開いて保存 | 結果画面を開き、「すべて保存」で取り出す |
| 続きを測定 | センサーを許可し直して装着確認へ。残りのブロックを同じ被検者のデータとして測定する |
| 削除 | 端末から消す（「ファイル」アプリに保存できたことを確認してから） |

> ブロックの**途中**で閉じた場合、そのブロックは控えられていません（終了済みのブロックのみ）。「続きを測定」からそのブロックをやり直してください。
>
> 控えはSafariとホーム画面アプリで別々に保存されることがあります。測定に使った方（通常はホーム画面アプリ）で開いてください。

## 5. 出力データ

### `<ID>_<方法>_<日時>_summary.csv` — 工程サマリー（1行 = 1工程、最大36行）

| 列 | 内容 |
|---|---|
| `method` | 測定方法（Ao / Bc など） |
| `block_no` / `eye` / `plane` | ブロック番号 / open・closed / frontal・sagittal |
| `step_no` / `step_code` / `direction` | 工程番号（0＝正中位）/ P15・N30・F15・B30 等 / 表示した方向名 |
| `target_deg` | 目標角（前＋/後−、右＋/左−の符号付き） |
| `peak_angle_deg` | 目標方向への到達最大角 |
| `hold_mean_angle_deg` | 保持相の平均角（正中位工程では静止時の平均角） |
| `tilt_duration_s` | 傾斜開始→目標到達の所要時間 |
| `mean_angvel_dps` | 平均角速度（到達角 ÷ 所要時間） |
| `peak_angvel_dps` | 最大角速度 |
| `peak_linacc_ms2` | 最大合成直線加速度（重力除去済・生値） |
| `peak_linacc_lp05_ms2` | 同・時定数0.5秒のローパス後の最大値（**解析にはこちらを推奨**） |
| `noise_sd_ms2` | 装着確認時に測った静止ノイズの標準偏差（機器の健全性の記録） |
| `hold_duration_s` | 保持時間 |
| `t_step_start_ms` / `t_tilt_start_ms` / `t_reach_ms` / `t_end_ms` | **ブロック開始（＝録音0秒）からの時刻** |
| `video_file` | 対応する音声／動画ファイル名 |

NRS列はありません。別紙シートの値は解析時に `block_no` + `step_no` で突き合わせてください。

### `<ID>_<方法>_<日時>_<open|closed>_raw.csv` — 生波形（約60 Hz、ブロックごとに1ファイル）

`t_ms`（ブロック開始基準）, `block`, `eye`, `plane`, `pattern`, `step_no`, `step_code`, `target_deg`,
矢状面角/前額面角, 加速度センサーのみの角度, 角速度, 生ジャイロ3軸, 直線加速度3軸＋合成＋平滑後, 重力ベクトル3軸, `phase`, `event`。

`event` 列に `MID_START` / `MID_END` / `STEP_START` / `TILT_START` / `TARGET_REACHED` / `RETURN_END` / `STEP_END` / `SKIP_FWD` / `SKIP_BACK` / `BREAK_START` / `BREAK_END` / `LAP1` … が入ります。オフライン再解析はこの列を基準に区間を切ってください。

### 録音／録画
1ブロックにつき1ファイル。記録の 0 秒 ＝ ブロック開始 ＝ CSVの `t_ms = 0` です。

| モード | 内容 | 目安サイズ |
|---|---|---|
| **音声のみ**（既定） | `P001_open_A.m4a` | 約0.5 MB/分（1ブロック約5 MB） |
| 動画＋音声 | `P001_open_A.mp4`（320×240・15 fps・約0.25 Mbps） | 1ブロック約20 MB |
| 記録なし | センサーCSVのみ | － |

傾斜のタイミング・角度・速度はすべてセンサーCSVに記録されるので、**通常は音声のみで十分**です。音声には検者の指示、被検者の発言、ブロック開始・終了の同期ビープが入ります。

保存のしかたは「4.5 データの保存と復元」を参照してください。

> **推奨**: **1ブロック終わるごとに**、ブロック選択画面の「このブロックのデータ」から生波形CSVと音声を保存してください。最後に結果画面の「すべて保存」で工程サマリーCSVも含めて保存します。端末内にも自動で控えが残りますが、「ファイル」アプリへの保存が正本です。

## 6. 角度の定義

重力（鉛直）を 0° とする絶対角です。装着オフセットは減算していません（表示・記録は絶対角のみ）。

- 矢状面角 = `atan2(g_z, √(g_x²+g_y²))` … 端末前方向への傾き（前傾 +）
- 前額面角 = `atan2(g_x, √(g_y²+g_z²))` … 端末右方向への傾き（初期設定で反転し、患者の右傾斜が +）

単一平面の傾斜では厳密に一致します（検証済: 前傾20°入力→20.00°出力）。矢状・前額が同時に大きく生じる複合傾斜では、この分解式の性質上わずかに相互干渉します（例: 前傾20°＋側屈30°同時 → 矢状17.2°表示）。本プロトコルは単一平面課題のため実用上の問題はありませんが、複合成分が疑われる試行では `raw.csv` の重力ベクトル3軸から任意の定義で再計算できます。

## 7. 測定上の注意

- **同一被検者内で傾斜速度をそろえる**ことが本アプリの主目的です。速度ゲージが緑に収まる範囲（初期値 3–8 deg/s）で操作し、`peak_angvel_dps` と `peak_linacc_ms2` を共変量として保持してください
- 端末に触れると加速度アーチファクトが出ます。自動検出をONにして、傾斜中は画面に触れない運用を推奨します
- 傾斜は徒手介助で行うため、検者の手の力の入り方も速度に影響します。試行間の速度のばらつきは `summary.csv` で必ず確認してください
- 転倒リスクのある被検者では、必ず前後左右に介助者を配置してください
- **直線加速度の読み方**：スマホの加速度センサーは常に0.02〜0.1 m/s²程度のノイズを含みます。ゆっくり傾ける課題では本来の並進加速度がこれと同程度かそれ以下になるため、画面表示は時定数0.5秒で平滑化した値を出しています。**傾斜の速さの指標としては角速度（deg/s）のほうが桁違いに信頼できます**ので、試行間の均一性は `mean_angvel_dps` / `peak_angvel_dps` で評価してください
- **目標角速度の目安**：1.5 deg/s では30°傾けるのに20秒かかります。恐怖感への加速度の混入を抑える意図としては妥当ですが、実施時間が1ブロック20分以上に伸びます。3〜5 deg/s（30°で6〜10秒）程度が現実的な落としどころです
- 本アプリは研究用途を想定した記録支援ツールであり、医療機器ではありません

## 8. うまく動かないとき

| 症状 | 対処 |
|---|---|
| 角度が0のまま／`0 Hz` | HTTPSで開いているか確認。Safari設定の「モーションと画面の向きのアクセス」をON。ページを再読み込みして「許可」 |
| 前後・左右の符号が逆 | 装着確認画面の「符号反転」ボタン |
| 角度がじわじわドリフトする | ジャイロ較正をやり直す。それでも続く場合は較正せず加速度のみモードで使用（ドリフトしません） |
| 傾けていないのに角度が振れる | 較正未実施だと並進加速度の影響を受けます。STEP 3 のジャイロ較正を実施 |
| 記録モードが選べない | iOSが14.3未満。設定→一般→ソフトウェア・アップデートで更新するか、外部レコーダー＋ビープ同期で運用 |
| 音声・動画が保存できない | 保存ボタン → 共有メニューの「"ファイル"に保存」を選ぶ。共有メニューを閉じてしまったら、もう一度ボタンを押す |
| 保存中に画面が戻らなくなった | アプリを閉じて開き直す。最初の画面の「端末内に残っている測定データ」→「開いて保存」から取り出せる |
| オフラインで開けない | 一度オンラインでアプリを開き、「オフライン準備 完了」を確認してからホーム画面に追加し直す |
| 途中でアプリが落ちる | 記録モードを「音声のみ」にする。他アプリを終了し、ブロックごとにデータを保存してから次へ進む。終了済みのブロックは「端末内に残っている測定データ」から取り出せ、「続きを測定」で残りを実施できる |
